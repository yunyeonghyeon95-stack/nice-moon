# NICE MOON

스크롤 위치에 맞춰 브랜드 영상이 재생되고, 기업 소개 문장과 수치가 단계적으로
전개됩니다. 이어지는 4대 주요 사업은 고정 화면에서 한 장씩 교체되며,
예약 버튼과 푸터는 정적인 형태로 마무리되는 NICE MOON 랜딩페이지입니다.

## Vercel 배포

1. 이 압축파일을 해제합니다.
2. 폴더 전체를 GitHub의 `nice-moon` 저장소에 올립니다.
3. Vercel에서 해당 저장소를 선택하고 **Deploy**를 누릅니다.
4. Framework Preset은 `Other`, Build Command와 Output Directory는 비워둡니다.

별도의 설치나 빌드는 필요하지 않습니다.
